# Unraid templates

Community Applications templates for my homelab tools.

| App | Description | Source |
|---|---|---|
| NetSentry | Network inventory, CVE matching and log review summarised by a local Ollama model | https://github.com/netadmindave/netsentry |

Install from the Unraid **Apps** tab, or copy an XML from `templates/` to
`/boot/config/plugins/dockerMan/templates-user/` and use Docker → Add Container.

Template problems: open an issue here. App problems: open an issue on the app's repository.

Templates are MIT licensed; each app keeps its own license.
